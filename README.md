# Aura — Hamrah AI Secretary Blueprint

This repository contains the complete build blueprint for Hamrah, an AI-powered personal secretary for iPhone, including the roadmap, master build prompt, Agent Factory and Skill Factory specifications, schemas, security requirements, and acceptance tests.

The complete package archive will be added as `hamrah_ai_secretary_blueprint_complete.zip`.

Project goal: build a native iPhone personal assistant with a backend orchestrator and a safe, testable system for creating, validating, versioning, approving, publishing, pausing, and rolling back user-defined agents and skills.

Important: this repository currently contains specifications, not a completed iOS app. The coding agent must implement and test the software phase by phase, report blockers honestly, and never claim unverified integrations work.
